## 2. 开工前六问（只问一次）

能从上下文推断的不要问。

1. **画幅**：16:9 横屏 / 9:16 竖屏 / 其他。交付前必须 `ffprobe` 核对 1920×1080。
2. **时长**：多少秒；VJ 是否需要首尾无缝。
3. **音乐**：用户给的音频 / 视频里的歌 / 不要音乐（默认 **120 BPM**，一拍 0.5 s）。音乐不够长时按小节重排拓展。
4. **名字 / 水印**：要做成**视觉符号**，不能只是打一行字。
5. **配色禁忌**：例如「不要粉色」。说过一次就要全程记住。
6. **参考资料**：小红书/抖音链接通常抓不到（robots 屏蔽），直接请用户发截图；「只做参考」时学手法，不照抄画面。

## 3. 五层结构（每个镜头的最低配置）

「炫酷」不等于铺满画面，而是**多层次 + 多动态 + 技术感**。

| 层 | 内容 | 运动特征 |
|---|---|---|
| 1 背景 | 渐变、噪声星云、天空、粒子场 | 慢速漂移 |
| 2 主体 | Logo、3D 物体、大字、剪影 | 主导视觉重心 |
| 3 装饰 | HUD 线框、轨道环、扫描线、涂鸦、光束、星闪 | 中速，可高频 |
| 4 前景 | 花瓣、光斑、散景、光速线 | 快速掠过，制造景深 |
| 5 后期 | **只让高光发光**的 bloom、色差、颗粒、暗角、偶发故障 | 全片统一 |

常见失败模式：只做了 1+2，画面「干净但廉价」；或者 1+2+3 全都静态，动效只剩主体在动。

## 4. 卡点

### 4.1 测 BPM 与相位

1. numpy 做 STFT，分别计算低/中/高频段的 onset flux。
2. 在 BPM 60–180 与相位上做**网格搜索**，取让 flux 峰值落在拍点上的组合。
3. 分频段确认：底鼓看低频，军鼓看中高频。
4. 记录三个量：`BP`（每拍秒数）、`B0`（第一小节起点）、军鼓时刻（如 `0.924 + k·1.2685`）。

### 4.2 时间线公式

```js
const BP = 0.5, B0 = 0, B = n => B0 + n * BP;      // 120 BPM
const SH = [[0, B(8), 'intro'], [B(8), B(16), 'gal'],
            [B(16), B(24), 'cuts'], [B(24), DUR, 'outro']];   // 右端点必须写真实 DUR
```

**所有**时间点都走 `B(n)`。绝对秒数（`t > 3.2`）会在换 BPM 后整体漂移。

### 4.3 可用脉冲函数

```js
const pulse   = (t, k = 7) => Math.exp(-(((t - B0) % BP + BP) % BP) * k);      // 每拍衰减
const beatHit = (T, t0, k = 9, a = .5) => { const p = T - t0; return p >= 0 && p < .5 ? Math.exp(-p * k) * a : 0; };
const sm      = (t, fps = 12) => Math.floor(t * fps);                          // 定格帧号，用于 jitter/boil
```

缓动：`eio` / `eout` / `ein` / `expo` / `back`（弹出）。

### 4.4 轻重分配

| 拍位 | 效果强度 |
|---|---|
| 强拍 / 军鼓 | 闪白、色差冲到 6–10 px、径向缩放模糊、故障切片 |
| 弱拍 | 只做轻微亮度脉冲（≤0.15） |
| 快切段 | 每拍一切，连续 4–8 拍，放在副歌前或高潮 |

**不要每拍都炸**。全片都炸等于没有重点。

### 4.5 帧率分层（高级感的来源）

- 拼贴、贴纸、手绘、涂鸦元素 → **12 fps 抖动**（`boil`，用 `sm(t,12)` 取帧号）
- 主体与摄像机 → **60 fps 丝滑**

两种节奏并置，观感会明显高于全程单一帧率。

## 5. 转场库

挑着用，**不要连续两次用同一种**。

| 转场 | 实现要点 | 适用 |
|---|---|---|
| 穿越画框 / 窗口推进 | 缩放 + 径向模糊，闪白落在下一拍 | 章节切换 |
| 曲速跃迁 | 星线拉长（放射状线段，长度按 `sin(π·u)` 调制） | 进入高潮 |
| 像素拖影 | 横向拉丝 / 竖向滴落（算法见 §7.4） | 故障段 |
| 方块拼贴洗牌 | 网格切块，每块按 hash 延时归位 | 收拢到 Logo |
| 横条错位 | 画面切 6 条，各自横移后再对齐 | 冲击镜头 |
| 纸条撕开飞走 | 沿路径裁剪 + 位移 | 露出下一场景 |
| 长曝光残影 | 多个半透明分身 | 速度感 |
| 星座连线变实体 | 点按顺序连线 → 线段收束成笔画 | 宇宙主题 |
| 光环绕转后炸开 | 物体被吸成光环，绕 Logo 旋转后散开 | 定版前 |
| 压成细线消失 | 水平缩放 → 0.002 + 淡出 | 收尾 |

## 6. 色彩与质感参数

### 6.1 后期参数表

| 参数 | 常态 | 鼓点峰值 | 备注 |
|---|---|---|---|
| 色差（RGB 通道错位） | 1–1.5 px | 6–10 px | 用 `globalCompositeOperation='lighter'` 按通道错位重绘 |
| 颗粒 | 0.05 | — | `overlay` 混合，预生成 4 帧循环 |
| 暗角 | 0.35 | 0.35–0.46 | 径向渐变，从 `H*0.42` 到 `H*1.02` |
| 闪白 | — | 0.2–0.35 | 指数衰减，`k=13~14`，不要 `k<9`（拖太长） |
| bloom | 阈值发光 | — | 只让高于阈值的部分发光，禁止整片加亮 |
| 编码 | crf 16 | — | 调色交付用 16，预览可用 18 |

### 6.2 冷暖反差

记忆点来自**冷暖对撞**：主调暖（阳光、奶油、金），在关键节点闪 0.25 秒冷色（克莱因蓝 #1838ff）的故障拖影。

### 6.3 铬金属

- 必须反射**有内容**的环境：天空、云、地平线、亮地面。纯黑环境会让铬字发脏发暗。
- `MeshPhysicalMaterial`：`metalness 1`、`roughness 0.1`、`clearcoat 1`，可选 `iridescence` 做珍珠虹彩。
- 色调映射 ACES，曝光 **1.1–1.3**。
- 镜面高光处放 glint 精灵。

### 6.4 禁忌色替换

| 禁用 | 替代 |
|---|---|
| 粉 | 银白 `#e4eaff` / 冷紫 / 星光金 |

## 7. 技术管线

### 7.1 路线 A：2D Node canvas

适合文字、HUD、粒子、MV 字幕。速度快，无损。

```bash
ffmpeg -f rawvideo -pix_fmt rgba -s 1920x1080 -r 60 -i - \
       -c:v libx264 -crf 16 -pix_fmt yuv420p out.mp4
```

- 运动模糊：在快门时间内渲染 N 个子帧再求平均。
- 后期（色差/颗粒/暗角）在 2D 内完成，按通道错位绘制。
- 字体：`GlobalFonts.register(buffer, name)`。

### 7.2 路线 B：three.js 跑在无头 Chromium

```bash
esbuild scene.js --bundle --format=iife --loader:.woff=binary --outfile=bundle.js
```

- `--loader:.woff=binary` 把字体**嵌进 bundle**，避免 `file://` 读取被拦截。
- 启动参数：`--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist`
- 页面暴露 `window.ready` 与 `window.renderFrame(t)`。
- 驱动流程：`renderFrame(t)` → 对 `#out` 截图（JPEG q96）→ `-f image2pipe -c:v mjpeg` 送 ffmpeg。
- 素材构建可能 1–2 分钟：`page.goto` 用 `{waitUntil:'commit'}`，`waitForFunction` 超时放宽到 900000、轮询 1000 ms。

### 7.3 3D 铬字构建

1. `opentype.parse` 读字体 → `font.getPath(text, 0, 0, 200)`
2. 路径转 `THREE.ShapePath`，**y 取负**
3. `toShapes()` —— `isCCW` 必须实测：校验 shape 数 == 字母数、hole 数 == 字母内洞数，否则会丢字母
4. `ExtrudeGeometry` 挤出，开启 bevel（倒角大一点更圆润饱满）
5. 材质见 §6.3
6. 环境贴图：画一张 equirect canvas → `PMREMGenerator`

### 7.4 2D 故障特效算法

**像素拖影**

1. 当前画面快照到 `SNAP`
2. 按 2–8 px 高的行带处理，每带用 hash 选一列 `x0`
3. `drawImage(SNAP, x0, y, 2, bh, x0, y, len, bh)` —— 把这一列横向拉长

**竖向滴落**：同法，改为按列拉伸。

**切片错位**：整段横条整体平移。

**单色 duotone**：先 `saturation` 混合模式填灰，再 `color` 模式填 `#1838ff`。

### 7.5 2D + 3D 混合

开多个 `WebGLRenderer`：

- 一个渲染 Logo（`alpha: true`）
- 一个渲染 shader 背景（水波焦散、迷幻漩涡）
- 一个做最终后期

主 2D canvas 用 `drawImage(glCanvas)` 合成，最后统一过一遍后期 shader。

## 8. 性能与并行

| 指标 | 上游文档 | 本机实测 |
|---|---|---|
| 3D（swiftshader） | 1–3.5 s/帧 | **0.33–0.53 s/帧**（单帧无模糊）<br>**0.83 s/帧**（4 子帧运动模糊） |
| 2D 720 帧（12 s） | 未给 | **120 s**，14 MB |
| 2D 1200 帧（20 s） | 未给 | **71 s**，18.1 MB |

差异原因是 CPU 核数与 `@napi-rs/canvas` 版本，不构成普遍结论。

### 并行分段

1. `nproc` 看核数，按核数切帧区间
2. 每段写完落一个 `OUT.done` 标记文件
3. 后台等待：`until [ -f a.done ] && [ -f b.done ]; do sleep 30; done`
4. 最后 `concat` 拼接

### 进程管理陷阱

- **不要** `pgrep -c` / `pkill -f render.js`，会把自身算进去、把自己杀掉。用 `"[r]ender.js video"` 这种写法。
- **不要** `cd` 之后用相对通配符删除。输出到新目录更安全。

## 9. 音频

### 9.1 拓展到目标时长

- 按小节切片，挑合适小节重复或重排
- 拼接处 **20–50 ms 交叉淡化**，接点落在小节线上
- 结尾淡出，或回到开头小节形成闭环

### 9.2 歌词对齐（MV）

- faster-whisper `medium` 取词级时间戳
- **必须传 numpy 数组**：先用 ffmpeg 解码成 16k 单声道 float32。直接传文件会触发 av 的 metadata 报错
- 以用户给的歌词文本为准，whisper 只取**时间**
- 字幕动画：逐字出现 / 解码乱码 / 按词高亮；重点词放大或加特效
- 歌词里的动作可做画面互动（唱到「吻你」时出现唇印或光斑聚焦）
- 截取片段时视频从 0 开始，歌词时间要减去偏移

### 9.3 纯画面 VJ

固定 **120 BPM**：一拍 0.5 s，30 s = 60 拍 = 15 小节。现场接 60 或 120 BPM 的歌都能对上。

## 10. 工程写法约束

| 约束 | 原因 |
|---|---|
| 每个镜头写成 `shotX(ctx, localT)` | 转场时要把两个镜头渲进缓冲区再做撕纸/方块/横条合成 |
| 快照缓存 | 马赛克/方块拼贴需要别的镜头某一刻画面，渲一次缓存，不要每帧重算 |
| 镜头开始时复位共享对象 | 否则上一个镜头的星系位置残留，导致铬字特写发灰 |
| 全局对象的画布要每次重设 ctx | 涂鸦器之类会画到错误的画布上 |
| 摄像机避免正俯视 | up 向量与视线平行会退化，改斜俯视 |
| 确定性随机 | 一律 hash，禁止 `Math.random()`，否则同帧不可复现 |

## 11. 无缝循环（VJ）

1. 让一个镜头**跨越接缝**：从时间轴末尾开始，在开头结束
2. 局部时间 `u = T >= 28 ? T - 28 : T + 2`，所有运动基于 `u`。**不要用 `T % 30`**
3. 前一个镜头的转场要落到该镜头 `u=0` 的状态（画框合拢、Logo 归位）
4. 交付前把**最后一帧与第一帧并排对比**

## 12. 质检与交付

### 12.1 三层质检

| 层级 | 做法 | 检查项 |
|---|---|---|
| 单帧 | 每镜头取 1–2 个时间点，`still` | 缺字母、铬字发灰、元素重叠、空洞黑屏、文字溢出、涂鸦画错画布 |
| 分镜 | `sheet` 一张图看整条节奏 | 镜头之间是否雷同、有无黑屏空档、切点是否跳 |
| 全片 | `ffprobe` + 抽帧 `fps=1/1.5,tile=4x5` | 帧数/分辨率/帧率/时长；循环片首尾并排 |

**顺序不可颠倒**。渲完整片再回看，时间成本高一个数量级。

### 12.2 合成命令

```bash
ffmpeg -i video.mp4 -i audio.m4a \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart out.mp4
```

### 12.3 封面

- 从最帅一帧的**构图**出发，单独高分辨率重渲，**不要直接截帧**
- 大字标题 + 水印
- 留出平台 UI 遮挡的安全区
- 3:4 与 4:3 各自重新构图，禁止简单裁切

### 12.4 交付说明必写

分镜要点、卡点方式（BPM）、规格、循环说明、已知限制（例如素材是程序画的而非实拍）；用了网络资料则附来源。

主动提供可选项：多比例封面、平台文案、竖屏版、加长循环版。

## 13. 坑清单

### 13.1 上游原有

| 现象 | 原因 | 解法 |
|---|---|---|
| 中文显示成方框 | 西文字体无 CJK 字形 | 字形池单独换 CJK 字体 |
| 音频 JSON 出现 `NaN` | 空频段 | 替换为 0 |
| 参数名遮蔽同名函数 | 参数叫 `label`，又有 `label()` | 参数改名 `lab` |
| 批量改文件改错位置 | 未确认匹配数 | 先 grep，断言 replace 匹配数 == 1 |
| `npm i --no-save` 把包删了 | 它会删掉不在 package.json 里的包 | 补 `package.json` |
| `node esbuild` 跑不起来 | `bin/esbuild` 是 ELF 原生程序 | 直接执行或 `npx esbuild` |
| 小红书抓不到 | robots 屏蔽 | 请用户发截图，不要绕 |

### 13.2 本仓库实测新增

| 现象 | 原因 | 解法 |
|---|---|---|
| 对主 canvas 加 `scale/rotate`，文字不动 | 文字画在离屏图层上 | 变换放进后期合成，`drawImage` 时施加 |
| 元素画了却几乎看不见 | alpha 同时写进 `rgba()` 和 `globalAlpha`，相乘 | 只由 `globalAlpha` 控制 |
| 快门黑条/闪白不出现 | 画在文字合成之前，被文字盖住 | 一律进 post 阶段 |
| 收尾动画永不触发 | 时间区间右端点写成 `99`，`u` 恒为 0.01 | 右端点写真实 `DUR` |
| 多个镜头看起来一样 | 主标每镜头都居中同尺寸 | 改主体形态（缩放/换水印/换构图） |
| 首帧字体回退成默认 | `@font-face` 未就绪就渲染 | `document.fonts.load` + `delayRender` |
| 并行脚本把自己杀了 | `pkill -f` 匹配到自身 | PID 文件或 `"[r]ender"` 写法 |
| 场景切换出现 3–5 帧全黑 | 前幕淡出与新幕首个动画之间有空档 | 新幕首个动画从 local frame 0 开始，或提前 6 帧起播 |
